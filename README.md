# Form

A focused infinite-canvas drawing app built with React, TypeScript, SVG, and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Included

- Infinite pan-and-zoom canvas with a responsive dot grid
- Selection, movement, and resize handles
- Rectangles, ellipses, diamonds, lines, arrows, and text
- Stroke, fill, and line-weight controls
- Keyboard shortcuts, undo/redo, local persistence, and SVG export
